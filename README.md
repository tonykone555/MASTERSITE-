# Immersive Interior Master

Standalone outreach/demo website — deliberately separate from YNOT.

## What is included
- user-uploaded interior video #1, optimized as the hero background
- user-uploaded 83.8s tour compressed to ~17s and scrubbed by scroll
- desktop + mobile responsive layout
- configurable company name, location, email, headline and intro in `config.js`
- premium project gallery using high-quality supporting imagery
- future-ready / immersive-screen positioning section

## Personalizing a prospect
Edit `config.js`, then replace the project image URLs in `script.js` with their scraped catalogue/project images.

## Deployment
This is a zero-build static website. Point a separate Vercel project at this folder (or any new Git repo containing it). No YNOT code is required.
